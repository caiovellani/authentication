# Authentication App 🔐 – Flutter

A simple and secure **Authentication** app built using **Flutter**. This app demonstrates how to implement user authentication using Firebase and other authentication mechanisms like email/password, Google sign-in, and more.

## 🛠️ Tech Stack

- **Flutter** – Framework for building natively compiled applications for mobile, web, and desktop
- **Dart** – Programming language used for Flutter development
- **Firebase Authentication** – For managing user authentication
- **Provider** – State management for handling authentication state
- **Cloud Firestore** – For storing user data
- **Google Sign-In** – For integrating Google authentication

## ✨ Features

- Email/Password-based authentication
- Google Sign-In integration
- User registration, login, and logout functionality
- Secure password reset and email verification
- Real-time user session management
- Responsive UI with smooth transitions

## 📦 Getting Started

### Prerequisites

- Flutter SDK installed
- Firebase project setup with Firebase Authentication enabled
- A code editor like **Visual Studio Code** or **Android Studio**

## Steps to Run Locally

### Clone the repository:

```bash
git clone https://github.com/caiovellani/authentication.git
cd authentication
```

### Install dependencies:
```bash
flutter pub get
```

### Set up Firebase for your Flutter project: 
	- Follow the official Firebase documentation to integrate Firebase with your Flutter app.
	- Ensure Firebase Authentication is enabled on your Firebase console.

### Run the app:
```bash
flutter run
```
